# HKBusETA · 巴士到站

一个面向香港公交的 **PWA（渐进式 Web 应用）**，纯前端、无构建步骤。数据来自 [DATA.GOV.HK](https://data.gov.hk/) 开放数据（九巴/龙运、城巴、岭巴）及香港天文台，支持离线缓存、安装到主屏幕、浅/深色主题与简体/繁体/英文三语。首个常用站点为「云汇 / St. Martin」。

> 当前版本：**v1.4.3**（图标更新：BusETA 站牌 + 抽象化 RTKG）

## 功能

- **到站**：选站点查看实时到站；无实时数据的九巴线路按官网班表推算下一班开出与到站时间；顶部快捷栏提供实时定位与常用站点切换。
- **行程**：预置快捷行程（含青沙转机、去旺角东等），可自行添加与排序。
- **线路**：搜索线路查看沿途站点、首末班、车费与推算到站；27A / 806A / 806B 为内置静态时刻表。
- **附近**：1 公里内站牌，支持 GPS 实时定位与手动输入站名/坐标，同名站柱合并。
- **我的**：常用站点/关注线路编辑、语言/主题/字号设置、数据缓存导入导出。
- **离线优先**：Service Worker 缓存应用外壳与本地数据，断网时显示缓存及更新时间。

## 快速开始

纯静态站点，无需构建。以本项目根目录起任意静态服务器：

```bash
python3 -m http.server 3000 --bind 0.0.0.0
# 打开 http://localhost:3000/
```

> ⚠️ Service Worker 与 Web App Manifest 需要 HTTPS 或 `localhost` 才能生效；直接用 `file://` 打开会导致 PWA 能力失效、接口跨域受限。

## 项目结构

```
.
├── index.html              页面骨架 + 顶栏 + 五个页签容器
├── app.js                  全部业务逻辑（单文件，按 /* ===== 注释分区）
├── style.css               全部样式（顶部 :root 为主题变量）

```

## 数据源

| 来源 | 用途 |
|---|---|
| `data.etabus.gov.hk/v1/transport/kmb/*` | 九巴/龙运实时到站、站点、线路-站点 |
| `rt.data.gov.hk/v1/transport/{citybus,nlb}/*` | 城巴、岭巴实时到站与站点 |
| `data.weather.gov.hk/weatherAPI/opendata/weather.php` | 实时天气 |
| `search.kmb.hk/.../FunctionRequest.ashx` | 官网补充：站点、时刻表、行车时间、实体站牌编号 |

实时接口浏览器直连、不缓存；官网补充接口本地缓存 7/30 天并做并发限流。

## 班表推算

`app.js` 的 `scheduleInfo()` / `nextDeparture()` 将班表分为两类处理：

- **单点发车时刻**（如 82D 每日 07:15、18:10）：只在真实时刻点查找下一班，绝不按班距循环——避免推算出不存在的班次。
- **班距窗口**（如 272A `06:00-07:00` + 班距 15 分钟）：在真实服务时段内按班距推算。

## 运行数据

运行时用户设置存于浏览器 `localStorage`（键前缀 `bp_`），不随源码提交。可用「我的」页的导出/导入功能在设备间搬运。
